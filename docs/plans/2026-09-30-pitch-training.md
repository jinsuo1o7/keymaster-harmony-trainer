# 피치 트레이닝 재설계

## 목표와 범위
기타 학습자가 음높이의 방향, 두 음의 거리, 조 안에서의 위치를 듣고 구별한다.
기존 음 구분·멜로디·코드·진행 화면을 제거하고 듣기 중심의 피치 훈련으로 교체한다.
마이크 채점, 절대음감 판정, 코드 청음은 이번 구현 범위에 포함하지 않는다.
참고: https://www.musictheory.net/exercises (음·음정·코드 청음의 구분).
아래 순서와 추천 기준은 이 제품의 설계 판단이며 학습 효과를 보장하는 기준이 아니다.

## 학습 흐름
1. 높낮이: 기준음 다음 음이 낮은지, 같은지, 높은지 선택한다. 넓은 차이에서 반음 차이로 좁힌다.
2. 음정: 상행하는 두 음의 거리를 선택한다. 장3도·완전5도·옥타브부터 7가지 음정으로 넓힌다.
3. 계이름: 도–미–솔–도를 듣고 문제음의 상대 계이름을 선택한다. 도·미·솔부터 장음계 7음까지 넓힌다.
각 단계는 독립적으로 선택할 수 있고, 난이도는 회차 안에서 바꾸지 않는다.
계이름의 도는 고정 C가 아니라 문제마다 조가 바뀌는 이동도이다.

## 한 회차
- 시작 전에 정답이 공개된 예시를 원하는 만큼 듣는다.
- 10문제, 시간 제한 없음. 먼저 문제를 끝까지 듣고 선택한다.
- 최초 선택을 바로 채점한다. 다시 듣기는 감점하지 않고 정답 보기는 오답으로 기록한다.
- 오답에는 선택한 답과 정답, 반음 수 또는 계이름을 보여주고 각각 비교 재생한다.
- 다음 문제는 직접 넘긴다. 결과에서 점수, 틀린 항목, 같은 단계 반복과 오답 복습을 제공한다.
- 복습은 틀린 문제만 다시 듣고 푼다. 복습 점수는 본 회차 기록과 구분한다.
- 8/10 이상은 다음 난이도를 제안하되 자동 변경하지 않는다.
- 완료한 최근 20회 기록을 기기에 저장한다. 과거 음감 점수와 합산하지 않는다.

## 화면 설계
기존 디자인 토큰: 배경 #0a0e14, 표면 #121821, 본문 #e6edf3,
조작 #14b8a6, 정답 #f59e0b, 오답 #ef4444.
Geist 본문·제목, 음악 기호에만 Geist Mono. 설명은 왼쪽 정렬, 듣기 영역은 중앙 정렬.

    피치 트레이닝 / 짧은 안내
    [높낮이] [음정] [계이름]
    난이도 / 예시 듣기 / 10문제 시작

    단계 이름                         3 / 10 · 끝내기
    ───── 진행률 ─────
          기준음  ───  문제음
               [두 음 듣기]
    [답] [답] [답]
    피드백 / 선택한 소리와 정답 비교 / 다음 문제

동일 카드의 나열보다 하나의 듣기 공간을 중심으로 설계한다.
재생 전 높이 그림이나 음 이름으로 정답을 노출하지 않는다.
색상 외에도 정답·오답 문구를 제공하고 키보드 포커스와 모바일 줄바꿈을 지원한다.

## 기술 및 검증
새 문제 생성기와 새 오디오 재생기를 사용한다. 음높이가 정확한 oscillator와 일정한 음색·음량을 사용한다.
재생은 AudioContext 시계로 예약하며 중지·화면 이동·언마운트에서 취소한다.
오디오 실패 시 재시도 안내를 표시하고 답 선택을 열지 않는다.
기존 지판 훈련이 쓰는 오디오와 진행 기록은 보존한다.
문제 범위·정답 매핑·복습·저장 검증과 타입 검사, 빌드로 회귀를 확인한다.
