# 코드톤 지판 재설계

## 목표
특정 코드 그립을 재현하는 대신, 기타 지판 어디에서든 현재 코드의 핵심음을 찾고
다음 코드로 움직일 수 있게 한다. 모든 문제는 표준 튜닝의 0–12프렛 전체를 사용한다.
같은 음 이름이라면 줄과 옥타브에 관계없이 정답으로 인정한다.

## 학습 단계
1. 루트 지도: 5도권(C→F→B♭→E♭…) 순서로 제시된 음의 루트를 여섯 줄에서 한 번씩 찾는다. 음 이름과 지판 위치를 먼저 연결한다.
2. 코드 만들기: 루트와 코드 성질을 보고 1·3·5·7도를 순서대로 하나씩 찾는다. Maj7, m7, 7을 고를 수 있다.
3. 가이드톤: 코드의 3도와 7도만 찾는다. 코드 진행에서 성질을 가장 또렷하게 만드는 두 음에 집중한다.

각 단계는 독립적으로 선택한다. 난이도는 정답 위치를 보여주는 안내, 답을 누르기 전에 음 이름을 추론하는 보통,
정답 음 이름을 보지 않는 도전으로 나눈다. 이번 첫 구현에서는 안내/보통을 제공한다.

## 한 회차
- 시작 화면에서 단계와 코드 성질을 고른다. 루트는 매 문제 무작위로 바뀐다.
- 8문제. 한 문제에서 필요한 음을 모두 누르면 채점한다.
- 오답은 빨간 점으로 남기되 즉시 막지 않고 계속 찾을 수 있다. 최초 오답이 있으면 그 문제는 오답이다.
- 정답 뒤에는 전체 코드톤을 지판에 표시하고, 코드 사운드를 재생한다.
- 결과에서 점수와 오답 문제를 다시 풀 수 있다. 복습 점수는 원 기록에 합산하지 않는다.
- 완료 기록은 브라우저에 최근 20회까지 저장한다.

## 화면
전체 지판은 훈련의 중심이다. 0–12프렛을 가로로 고정하고, 낮은 E가 아래에 오도록 실제 연주 시점과
가깝게 배치한다. 3·5·7·9프렛은 단일 인레이, 12프렛은 이중 인레이으로 표시한다.

    코드톤 지판 / 짧은 설명
    [루트 지도] [코드 만들기] [가이드톤]
    코드 성질 / 예시 듣기 / 8문제 시작

    Cmaj7                       3 / 8
    1   3   5   7                ← 현재 찾을 음만 강조
    ─────────────────────────────
    0    1    2 ...           12
    ─────────────────────────────  high E
    ─────────────────────────────  B
    ...
    ─────────────────────────────  low E
    정답 또는 오답 피드백 / 다음 문제

기존의 좁은 창, A현 기준 앵커, 고정 7→1→3→5 순서, 그립 위치 기반 채점은 제거한다.
정답/오답은 색상과 텍스트 모두로 구분하며, 각 프렛 셀은 키보드로도 조작할 수 있다.

## 시각 방향
앱의 어두운 남색 표면과 Geist 글꼴을 유지한다. 지판에는 나무 질감이나 장식 이미지를 쓰지 않고,
현·프렛·인레이의 구조만 남긴다. 코드톤의 원형 마커가 한 문제에서 유일하게 강한 시각 요소가 된다.
루트는 청록, 현재 답은 호박, 공개된 다른 코드톤은 윤곽선으로 구분한다.

## 검증
표준 튜닝의 각 지점이 올바른 음 이름과 피치 클래스를 갖는지, 세 코드 성질의 1·3·5·7도가 정확한지,
각 문제에 필요한 답이 0–12프렛 안에 존재하는지, 중복 탭과 오답 복습 및 저장이 올바른지 테스트한다.
