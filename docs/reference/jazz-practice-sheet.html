재즈 기타 입문 연습 시트

재즈 스탠다드는 팝·록과 반대로 플랫 키가 지배적입니다. 관악기·보컬 편의로 쓰인 곡이 많기 때문이죠. 아래는 CAGED · 루트 스트링 · 스케일 · ii–V–I · 코드톤을 하나로 엮은 최소 생존 루트맵입니다.

01

우선순위 키 — 왜 플랫인가

리얼북 등장 빈도순. 메이저와 렐러티브 마이너를 한 세트로 익히면 암기량이 절반이 됩니다.

1CAm0Blue Bossa(Cm), 블루스
2FDm♭1Satin Doll, ATTYA 구간
3B♭Gm♭2Tenor Madness, Now's the Time
4E♭Cm♭3Autumn Leaves, A Train
5GEm♯1보컬 곡 다수
최우선 = C · F · B♭ · E♭. 이 네 키가 스탠다드의 큰 비중을 커버하고, ii–V–I 패턴이 반복돼 전이 학습이 잘 됩니다. 마이너는 렐러티브 관계라 스케일 음이 같아 별도 부담이 없습니다.
02

스케일 — 루트 2줄만

12키를 따로 외우지 않습니다. 6번줄 루트 포지션 1개 + 5번줄 루트 포지션 1개만 완성하면, 슬라이드만으로 어느 키든 만들 수 있어요. CAGED 5모양 완성은 그 다음 단계.

6번줄 루트 — C 메이저

루트가 6번줄 8프렛(C). E-shape 계열 박스. 루트를 옮기면 곧 다른 키.

5번줄 루트 — F 메이저

루트가 5번줄 8프렛(F). A/C-shape 계열 박스. 6번줄 셰이프와 짝으로 지판을 덮습니다.

ii–V–I — 화성의 뼈대

재즈 화성의 대부분은 ii–V–I 조각입니다. 네 키만 손에 붙이면 스탠다드 대부분이 익숙해집니다.

연습법: 한 키의 ii–V–I를 한 포지션 안에서 손을 크게 옮기지 않고 코드 이동 → 옆 키로. C · F · B♭ · E♭를 순환하면 5도권 감각도 함께 붙습니다.
04

코드톤 아르페지오 — R · 3 · 5 · 7

솔로의 뼈대는 스케일이 아니라 코드톤입니다. 아래는 모두 C 루트(6번줄 8프렛) 기준 — 슬라이드하면 어느 키든 됩니다.

m7 아르페지오

3도·7도가 ♭ (Cm7 = C E♭ G B♭)

7 (도미넌트) 아르페지오

7도만 ♭ (C7 = C E G B♭)

maj7 아르페지오

그대로 (Cmaj7 = C E G B)

가이드 톤(3도·7도)이 가장 중요합니다. 3도는 메이저/마이너를, 7도는 코드 성격을 결정해요. 예) C 키 ii–V–I 가이드 톤 라인: Dm7의 F(♭3) → G7의 F(♭7) → Cmaj7의 E(3). 3·7도만 부드럽게 이으면 스케일을 안 쳐도 재즈처럼 들립니다.
05

다음 주 최소 암기 세트

연주할 곡의 키를 먼저 확인하세요. 모르면 C부터. 아래를 순서대로 체크하며 연습하세요. (체크 상태는 저장됩니다)

우선순위 한 줄 요약: 곡 키 하나 → 6번줄 루트 스케일 → ii–V–I 아르페지오 → 3·7도 가이드 톤. 입문 솔로는 “맞는 음 + 좋은 타이밍”이 “많은 음”을 이깁니다. 4분음표 코드톤 + 스윙 필부터.
프렛 위치는 표준 튜닝(E A D G B E) 기준으로 계산되었습니다. 루트를 좌우로 옮기면 그대로 다른 키의 셰이프가 됩니다.
